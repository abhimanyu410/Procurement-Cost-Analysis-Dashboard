# Abhimanyu Singh — Analytics Portfolio

Three practical portfolio projects focused on procurement, operations, and analytics.

## Projects
1. **Procurement Cost & Supplier Performance Dashboard** — spend, category, supplier, lead-time, and delivery KPIs.
2. **Inventory Demand Forecasting** — monthly demand trends and a trailing three-month moving-average baseline.
3. **Purchase Assistant Search Prototype** — keyword search over a sample product catalogue and purchase orders.

## Run a project
Open a terminal in a project folder:
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data disclaimer
All datasets are synthetic portfolio examples. They do not represent Jai Bhawani Metal India or any real supplier. Do not use demo prices or forecasts for actual purchasing decisions.
