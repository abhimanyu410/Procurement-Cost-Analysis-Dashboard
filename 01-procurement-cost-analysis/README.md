# Procurement Cost & Supplier Performance Dashboard

A Streamlit dashboard built with Pandas and Plotly using synthetic purchase-order examples.

## Questions explored
- How does spend vary by category?
- Which suppliers account for the most spend?
- What are average delivery lead time and on-time delivery rate?
- How can filters support supplier review discussions?

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

The dataset is synthetic, not actual company or supplier data.

## Skills
Python, Pandas, Streamlit, Plotly, CSV handling, grouping, filtering, KPI definitions, and business reporting.
