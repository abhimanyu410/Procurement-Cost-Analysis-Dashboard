# Inventory Demand Forecasting

A beginner-friendly demand analysis and baseline forecast dashboard using synthetic monthly product demand.

## Features
- Product selection and monthly demand trends
- Trailing three-month moving-average baseline
- Historical demand compared with baseline
- Stockout-day indicators for inventory discussions

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

The moving average is a baseline, not a production-grade machine-learning model. All data is synthetic.
